# SolarAI-X 项目描述与面试要点

基于MCP和OpenAI兼容模型的材料分析Agent，提供自然语言交互、领域工具执行、科学计算与绘图。

- 集成9个MCP工具，加入白名单、Schema参数校验、调用轮次与超时控制；通过FastAPI/SSE输出过程，SQLite记录任务和会话，支持取消及重启后的状态恢复。
- 以真实模型与本机MCP验证12道固定任务，8道正向、4道负向均通过；核对实际工具轨迹、参数与数值、最终JSON及PNG产物。该结果限于单次固定演示验收。
- 基于公开光谱测量数据清洗去重得到149条论文/组分记录，按论文分组进行回归模型选择与留出评估；30条测试MAE为0.027 eV。保留一次模型参考、组分分组评估和低样本家族不可用状态。

公开测量模型不是新物理实验；二次模型MAE略优但RMSE高于一次参考，不能宣称全面领先。MAPbIBr满足当前部署门槛，其余三个家族仍不开放。关键词降级不冒充BGE语义效果，12任务不冒充通用Agent准确率。候选人须能说明实际参与和方法限制。
