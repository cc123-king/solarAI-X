# 遗失科学模型的公开资产核查

核查目标是找到有可用许可、输入语义兼容并可独立验证的替代资产。公开可访问不等于与本项目的模型兼容，不能拿通用语言模型权重替代器件回归模型。

| 来源 | 直接核实的信息 | 处理 |
|---|---|---|
| [TOPCon 作者数据 v2](https://data.mendeley.com/datasets/s2vnyfgc4s/2) | 数据许可 CC BY 4.0；主压缩包6,055,350,940 bytes；训练CSV1,893行，18输入、6输出；原 AutoGluon 1.1.0/Python3.10依赖与当前环境不同 | 只取136 KB压缩CSV；重新训练本项目数值森林；保持18字段，单独开放新工具。未下载6 GB包或执行作者pickle。见 [已实现恢复](PUBLIC_TOPCON_RECOVERY.md) |
| [Cs2AgBi0.75Sb0.25Br6 Physics-Guided ML](https://github.com/Dhawan4324/Cs2AgBi0.75Sb0.25Br6-Physics-Guided-ML) | MIT；README明确限定该双钙钛矿材料；9个输入，4个输出Voc/Jsc/FF/PCE；公开预处理xlsx约2.66 MB；名为Master_ML_Dataset.xlsx的文件仅2 bytes | 与现有窄/宽带隙工具的39字段、6输出不兼容；不下载训练表、不虚构Vm/Im，不把该材料假称为现有两类材料。可以另立材料范围后做独立模型 |
| GitHub 上 HTL-free、Rb2LiGaI6、Cs-based、FASnI3 等 SCAPS/ML 仓库 | 搜索元数据未提供明确仓库许可证；各自材料和结构不同，尚未逐个证明数据再利用许可和39字段匹配 | 仅保留研究线索，不复制代码或训练数据，不用于当前部署 |

钙钛矿窄/宽带隙的完整恢复仍需要一种可核实来源：原六组模型；同器件结构、明确单位与范围的输入/输出训练表；或可复现且获许可的物理模拟流程。当前公开线索不满足这些条件，因此这两个原工具保持明确不可用。已有的实测文献带隙基线与老化工具继续遵守各自验证范围，不能代替整电池六参数模型。

此表记录直接读到的文件目录、README、依赖和许可，不声称审计完全部互联网数据集或验证公开仓库中的论文成绩。
