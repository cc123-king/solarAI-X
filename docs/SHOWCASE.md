# SolarAI-X 三分钟演示

无需密钥的固定演示：在项目根目录执行 `python scripts/run_offline_demo.py`。模型选择由脚本预设，检索与带隙计算调用真实本地函数；此模式不经过真实SSE MCP传输。
真实模型与SSE MCP另用 `python scripts/evaluate_agent_live.py --live --max-cases 2`，需要已配置的模型服务并消耗额度。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:25 | 展示架构图与能力状态接口 | 9个工具；模型缺失时明确报告能力状态 |
| 0:25–1:00 | 展示固定任务或询问 MAPbIBr 在Br比例0.5的带隙 | 工具目录、Schema与组分校验、公式返回1.64 eV；说明未验证实验精度 |
| 1:00–1:40 | 真实模式计算Br比例0、0.5、1并绘图 | 多轮调用、SSE响应、PNG下载；离线时展示已有真实记录复盘 |
| 1:40–2:10 | 查看 /api/tasks 中的工具参数与结果 | SQLite任务与会话、取消、重启后中断状态 |
| 2:10–2:40 | 展示无效比例、未知工具或损坏PNG的失败用例 | 拒绝越界参数；业务错误不计成功；完整图片验证 |
| 2:40–3:00 | 展示回归和验证边界 | 138项离线回归，2条真实固定任务；不代表通用正确率或材料预测科学精度 |

已有真实记录的安全摘要见 [真实任务摘要](examples/real-task-summary.json)，[实际生成曲线](examples/bandgap-curve.png)。记录来自2026-10-18执行，v3仅复评该记录，没有新增模型样本。

可补充展示：三个缺少训练资料的带隙模型在能力表中为不可用，调用返回明确错误；详见 [科学模型契约](SCIENTIFIC_MODEL_V4.md)。
