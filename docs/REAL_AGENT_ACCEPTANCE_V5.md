# SolarAI-X 真实验收与公开测量模型 v5.1

本轮使用 qwen-plus，通过真实本机 MCP SSE 服务执行12道固定任务，单次运行12/12通过：8道正向任务全部通过，4道负向任务全部按预期处理。新增23次聊天请求、0次Embedding请求，SDK自动重试0，低于已批准的48次聊天上限。

正向任务核对了工具选择、实际参数与返回数值、最终JSON、曲线点和PNG文件；覆盖原公式上下界、多个输入、公开测量模型和两种方法对照。负向任务覆盖越界比例、旧模型不可用、低样本家族不可用、未知真实实验值。两道模型不可用题还核对了真实工具业务错误，连接失败不能替代正确拒答。

评测结束后，从本轮专用任务库提取实际工具事件，再离线评分12/12通过，没有新增模型调用。证据包提供JSON轨迹，不包含数据库或密钥。图表展示的是原公式计算，不是物理实验结果。

这是一组作者编写的12道固定演示验收，未覆盖通用Agent任务、并发、跨设备部署或全部9个注册工具，不能写成通用Agent准确率100%。单次运行也不能证明重复运行稳定性。

公开测量模型采用Perovskite Database v1.0.1（CC BY4.0，DOI 10.5281/zenodo.5837035）。697条符合测量依据的源记录去重为149条论文/组分记录。按论文分组的30条测试记录，所选二次Ridge MAE为0.0270 eV，训练均值基线为0.1064 eV。一次Ridge的MAE为0.0281 eV且RMSE更低，因此不能宣称复杂模型全面优胜。

独立组分划分流程另在内部验证选中一次Ridge，14条测试的MAE为0.0366 eV。该结果不冒充部署二次模型的跨组分分数。当前仅MAPbIBr满足家族样本和总体质量要求，其余三个家族继续不可用；无新增物理实验。

两套依赖环境各156项测试通过。代码和训练资料已写入本地项目，代码与验收记录随本次提交同步，远程CI以Actions记录为准。
