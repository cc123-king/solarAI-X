# SolarAI-X 公开测量基线与扩展任务 v5

本轮新增了可重现的公开测量数据模型，补上原先带隙系数没有训练来源的缺口。来源为 Perovskite Database v1.0.1，DOI 10.5281/zenodo.5837035，CC BY 4.0；源CSV的SHA-256、清洗规则、训练脚本、两种分组、模型系数和逐条测试预测均已保留。

## 数据与评估

从42443条数据库记录中，仅保留明确三维、铅基Cs/MA/FA-I/Br组成且有Absorption/EQE/Tauc光谱测量依据的697条记录，排除按组分推算的标签。相同论文和组分的重复记录取中位数，得到149条记录、133篇论文、36种组分。

按论文分组划分92条训练、27条验证、30条测试（27篇测试论文）。一次Ridge与二次Ridge仅按验证组MAE选型，部署二次Ridge，最终拟合不包含测试记录。预先候选的一次Ridge另作为参考报告，未按测试结果重新选择模型。

| 同一论文分组测试 | MAE eV | RMSE eV |
|---|---:|---:|
| 训练均值常数基线 | 0.1064 | 0.1671 |
| 一次Ridge参考 | 0.0281 | 0.0421 |
| 验证组选中的二次Ridge | 0.0270 | 0.0466 |

二次模型的MAE略低、RMSE高于一次模型，不能据此宣称复杂模型全面优胜。另按组分分组，在其训练/验证组内部独立选型后选中一次Ridge，14条未见组分测试记录的MAE为0.0366 eV；这与论文分组是两套评估流程。

## 可用范围

新增measured_baseline方法，API、MCP与页面共用透明JSON模型；保留原公式作为单独方法。只在训练组分的邻近覆盖范围内返回文献基线估计，缺失或损坏模型、越界组分均明确失败。通过真实本机MCP SSE验证了两种方法，未调用语言模型。

独立测试中MAPbIBr有17条记录，另外三个家族的测试数分别为3、3、1，少于当前部署要求的5条。三个家族继续不可用；对应负R2或不足以计算R2的分组结果完整保留，未用整体分数掩盖。没有新增材料实验，工艺与相变因素未建模，以上不能解释为通用材料预测精度。

## Agent验证

新增12道固定任务，8道正向、4道负向，覆盖两种计算方法、不同参数和方法关联、曲线实际PNG、越界输入、缺失/低样本模型、未知真实实验事实。评分同时核对实际工具轨迹与最终JSON；连接错误不会冒充模型不可用，捏造数值不能凭包含关键词通过。

真实评测工具冻结输入、模型、代码和本机MCP地址；新增聊天请求硬上限48，SDK重试0，每任务最多3轮工具调用、8次本地工具执行、每次最多768输出token。题集、标准答案与评分信息不发送给模型，只发送题目与工具交互数据。两套依赖环境各156项回归通过；本轮12任务的真实模型成功率尚未测量。

本轮演示验收目标为12任务至少10道通过、4道负例均不返回捏造科学数值，失败与耗时如实保留。这是本项目的验收目标，不是行业通用标准。
