# 独立训练种子说明

本目录保留 16 条作者构造的虚构种子：12 条训练、4 条训练验证。来源是显式构建的数据契约，不是外部人工标注，也不包含个人简历或线上会话。

SolarAI-X 种子用于单次工具选择和参数格式；从原本机工具链保留的 CareerPilot 种子用于原文结构化提取。它们验证训练数据格式和脚本流程，规模不足以证明微调收益。训练验证 loss 也不能代替完整 Agent 任务评估。

实际训练前应扩充、审核任务数据，维持来源和夹具分组隔离，并检查模型 Chat Template 与助手响应损失掩码。`--evaluation-manifest` 只接受只含分组标识的清单，训练器不会打开封存题。清单完整性由调用者负责，不得把验收题或对应输入输出混入训练。

本轮只合入代码和种子，没有下载基座、生成 LoRA 权重或启动 vLLM。训练脚本默认只验证数据；只有显式 `--run` 才执行训练，模型仅从指定本地目录加载，并拒绝覆盖输出。本仓库此次改动没有可复现的新训练成绩，不以历史同模板样例结果声明泛化提升。当前能力和验证边界见 [复现说明](../docs/RESUME_ALIGNMENT.md)。
